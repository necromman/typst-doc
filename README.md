# ⚔️ Typst RPG

**문서로 즐기는 방치형 RPG 게임**

Typst의 강력한 조판 기능을 활용하여, 게임 상태를 아름다운 문서 형태로 렌더링하는 독특한 RPG 게임입니다.

## 🎮 컨셉

- **문서형 UI**: 게임의 모든 정보가 Typst로 조판된 문서로 표현됩니다
- **방치형 게임플레이**: 자동 사냥을 설정하고 캐릭터의 성장을 지켜보세요
- **실시간 데이터 바인딩**: 게임 상태 변경 시 실시간으로 문서가 업데이트됩니다

마치 살아있는 소설책을 읽듯이, 캐릭터의 모험을 문서로 감상할 수 있습니다.

## ✨ 주요 기능

### 캐릭터 시스템
- **3개 클래스**: 전사, 마법사, 도적
- **클래스별 고유 특성**: 각 클래스마다 3개의 독특한 특성
- **레벨업 시스템**: 전투를 통한 경험치 획득 및 성장

### 전투 시스템
- **무한 자동 사냥**: 끊임없이 적을 처치하며 성장
- **동적 적 생성**: 캐릭터 레벨에 맞는 적 자동 생성
- **전투 로그**: 모든 전투 내역이 상세히 기록됨

### 아이템 & 재화
- **인벤토리**: 최대 20개 슬롯
- **다양한 아이템**: 장비, 소비, 재료 아이템
- **아이템 희귀도**: Common ~ Legendary
- **골드 시스템**: 적 처치로 골드 획득

### Typst 문서 렌더링
- **실시간 렌더링**: typst.ts (WASM)를 사용한 브라우저 내 렌더링
- **아름다운 조판**: 프로그레스 바, 표, 색상 등 풍부한 시각 요소
- **반응형 레이아웃**: 2단 그리드 레이아웃으로 정보 표시

## 🚀 빠른 시작

### 필요 환경
- Node.js 18+
- npm or yarn or pnpm

### 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```

브라우저에서 `http://localhost:3000` 접속

## 🎯 게임플레이

1. **캐릭터 생성**
   - 이름 입력
   - 클래스 선택 (전사/마법사/도적)

2. **자동 사냥 시작**
   - "자동 사냥 시작" 버튼 클릭
   - 실시간으로 업데이트되는 문서 감상

3. **캐릭터 성장**
   - 적 처치 → 경험치/골드/아이템 획득
   - 레벨업으로 스탯 증가
   - 인벤토리에 아이템 수집

## 🏗️ 프로젝트 구조

```
typst-doc/
├── src/
│   ├── engine/              # 게임 엔진
│   │   ├── character/       # 캐릭터 시스템
│   │   ├── combat/          # 전투 시스템
│   │   ├── item/            # 아이템 & 인벤토리
│   │   └── GameState.ts     # 게임 상태 관리
│   ├── typst/               # Typst 통합
│   │   ├── TemplateGenerator.ts  # Typst 코드 생성
│   │   └── TypstRenderer.ts      # Typst 렌더러
│   ├── web/                 # 웹 UI
│   │   └── styles.css
│   └── main.ts              # 엔트리 포인트
├── index.html
├── package.json
└── vite.config.ts
```

## 📊 클래스 특성

### ⚔️ 전사
- **강인한 체력**: 최대 HP +30%
- **철벽 방어**: 방어력 +50%
- **반격의 달인**: 10% 확률로 받은 피해의 50% 반사

### 🔮 마법사
- **마나의 흐름**: 최대 MP +50%
- **마법 증폭**: 공격력 +40%
- **지식의 축적**: 경험치 획득량 +20%

### 🗡️ 도적
- **그림자 은신**: 속도 +60%
- **치명타**: 25% 확률로 2배 피해
- **노련한 약탈**: 골드 획득량 +30%

## 🛠️ 기술 스택

- **Game Engine**: TypeScript
- **Typst Rendering**: typst.ts (WASM)
- **Frontend**: Vanilla TypeScript + HTML/CSS
- **Build Tool**: Vite
- **Document Markup**: Typst
